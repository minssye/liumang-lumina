# 榴芒启航 LUMINA

一个沉浸式开始页：全屏壁纸、大时钟、搜索、分类收藏。

打开即用，数据保存在本机浏览器，无需后端。

## 预览

用任意静态服务器打开即可：

```bash
python3 -m http.server 8000
```

浏览器访问 `http://localhost:8000`。

## 功能

- 全屏 Bing 壁纸，右下角换一张，左下角显示版权
- 大时钟与日期
- 必应 / Google / 百度搜索
- 底部分类 Dock，点击展开收藏
- 收藏图标可在正圆与圆角之间切换
- 设置面板：增删改分类和网站、拖拽排序、JSON 导入导出

## 用法

| 操作 | 说明 |
| --- | --- |
| 回车 | 搜索；输入关键词也可筛选收藏 |
| `!g` / `!b` / `!d` | 指定 Google、必应、百度；中文 `！` 同样可用 |
| 只输入 `!d` | 切换默认引擎，不清空收藏、不开新标签 |
| 点击底部分类 | 展开该分类的收藏 |
| 右键空白处 | 隐藏或显示收藏 |
| `/` | 聚焦搜索框 |
| 右下角 ⟳ | 换壁纸 |
| 右下角 ⚙ | 管理收藏 |

搜索指令大小写不敏感，支持全称与缩写：`g/google`、`b/bing`、`d/baidu`。`!g猫`、`！b 天气` 都可以；`!hello` 这类后面紧跟英文字母的按字面搜索。

## 文件

- `index.html` — 页面、样式与交互
- `favicon.svg` — 站点图标

收藏、最近访问、默认搜索引擎、图标形状都写在 `localStorage`。换浏览器或清站点数据后需要重新导入。
